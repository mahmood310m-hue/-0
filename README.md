# مدرسة كوثر الأهلية المختلطة

تطبيق عربي RTL مبني باستخدام React + Vite + Capacitor، ومجهز لبناء APK عبر GitHub Actions.

## تشغيل المعاينة محلياً
```bash
npm install
npm run dev
```

## رفع المشروع إلى GitHub
1. أنشئ مستودعاً جديداً باسم `kauthar-school-app`.
2. ارفع جميع محتويات هذا المجلد إلى الفرع `main`.
3. افتح تبويب Actions في GitHub.
4. اختر `Build Kauthar School APK` وانتظر اكتمال البناء.
5. افتح نتيجة التشغيل (Run) ثم Artifacts وحمّل `kauthar-school-debug-apk`.

## ملاحظات مهمة
- هذا إصدار أولي ببيانات تجريبية لعرض الواجهة وتدفق الصفحات.
- الإعلانات التي تضيفها من التطبيق تحفظ محلياً على الجهاز باستخدام LocalStorage.
- صفحات الدرجات والحضور والواجبات والجدول هي واجهات تمهيدية؛ لا يوجد حالياً تسجيل دخول أو قاعدة بيانات مشتركة أو مزامنة بين أجهزة.
- ملف APK الناتج من هذا المسار هو Debug APK للتجربة والتثبيت. للنشر الرسمي على Google Play يلزم إعداد توقيع إصدار Release وسياسة خصوصية ومراجعة متطلبات المتجر.
- غيّر بيانات الطلاب التجريبية قبل أي استخدام فعلي، ولا تضع بيانات طلاب حقيقية في نسخة تجريبية عامة.
